# Report Content — N-QPCA Based Quantum Noise Signature Analysis

## Abstract

Quantum noise can produce correlated variations across several measured response channels, making direct analysis of high-dimensional observations difficult. This project implements a 15-dimensional Quantum Principal Component Analysis (QPCA) based framework for extracting compact spectral noise signatures. A 3000-observation dataset containing fifteen response features under five controlled noise conditions is standardized and converted into a covariance matrix. The covariance matrix is normalized to form a density matrix and embedded into a sixteen-dimensional Hilbert space so that it can be represented by four qubits. A canonical purification of this density matrix is prepared in a state-vector simulator, and quantum phase estimation is applied to the unitary generated by the density matrix. The measured phase distribution provides estimates of the dominant eigenvalues, which correspond to the QPCA principal spectral components. The quantum estimates are evaluated against a classical numerical reference using eigenvalue error, explained variance, reconstruction error, noise-type separability, and noise-strength sensitivity. The result is a hybrid simulation framework in which QPCA is the central spectral-analysis method rather than an auxiliary demonstration.

## 1. Introduction

Quantum devices are affected by multiple noise mechanisms. Measurements from different response channels can therefore exhibit correlated and structured variation. A useful analysis method should reduce this high-dimensional information while preserving the dominant structure.

Classical PCA performs this reduction through covariance eigenvectors. QPCA uses a density-matrix representation and quantum phase estimation to access the spectral structure of that matrix. This project investigates QPCA as a noise-signature extraction layer.

## 2. Problem Statement

Given a set of multi-dimensional response measurements generated under different quantum-noise conditions, determine whether the dominant spectral components obtained using a QPCA-based computation can compactly represent the response structure and provide measurable signatures for different noise conditions and strengths.

## 3. Dataset

The supplied dataset contains:

- 3000 observations
- 15 response features
- 5 noise types
- a noise-strength parameter

The response features are grouped as X, Y, and Z measurements.

## 4. Methodology

### 4.1 Standardization

For each feature:

\[
z_{ij}=\frac{x_{ij}-\mu_j}{\sigma_j}
\]

### 4.2 Covariance

\[
C=\frac{1}{N-1}Z^TZ
\]

### 4.3 Density matrix

\[
\rho=\frac{C}{Tr(C)}
\]

The covariance matrix is positive semidefinite, and normalization gives a trace-one matrix suitable for density-matrix-based spectral processing.

### 4.4 N-dimensional embedding

There are 15 features. Four qubits provide a 16-dimensional Hilbert space because:

\[
2^4=16
\]

Therefore:

\[
\rho_{16}=
\begin{bmatrix}
\rho_{15}&0\\
0&0
\end{bmatrix}
\]

The added dimension is only zero padding.

### 4.5 QPCA state preparation

A canonical purification is constructed from the positive square root:

\[
|\Psi_\rho\rangle
=
\sum_j\sqrt{\lambda_j}|u_j\rangle|u_j^*\rangle
\]

This means the QPE measurement samples eigencomponents with probabilities related to the eigenvalues of the density matrix.

### 4.6 Quantum phase estimation

The simulator uses:

\[
U=e^{2\pi i\rho}
\]

If:

\[
\rho|u_j\rangle=\lambda_j|u_j\rangle
\]

then:

\[
U|u_j\rangle=e^{2\pi i\lambda_j}|u_j\rangle
\]

QPE estimates the phase:

\[
\phi_j\approx\lambda_j
\]

With eight ancilla qubits, the phase grid spacing is:

\[
\Delta\phi=\frac{1}{256}
\]

### 4.7 QPCA evaluation

The first three QPCA eigenvalues are compared against the classical eigenvalues. The project reports:

- absolute error
- relative error
- explained variance
- QPE probability normalization
- reconstruction error
- noise-type centroid accuracy
- noise-strength correlation
- per-noise spectral signatures

## 6. Discussion

The important observation is whether the dominant QPCA peaks align with the largest covariance eigenvalues. Because QPE has finite phase resolution, the quantum values appear on a discrete phase grid and may differ slightly from the continuous classical eigenvalues.

The noise-type evaluation shows whether different controlled noise conditions occupy different regions of the QPCA score space. The strength analysis checks whether the magnitude of the leading QPCA component changes systematically with the imposed noise strength.

## 7. Limitations

1. The implementation is a state-vector simulation.
2. State preparation is idealized.
3. The phase unitary is directly constructed from the density matrix.
4. No quantum speedup is claimed.
5. No real quantum-hardware result is claimed.
6. Zero padding adds a mathematical basis state but no physical feature.
7. QPCA principal components describe statistical spectral structure; they should not automatically be interpreted as individual physical noise mechanisms.

## 8. Conclusion

The project implements a complete 15-dimensional QPCA-based noise signature pipeline. The central computational stage is quantum phase estimation applied to a density-matrix representation of the full feature covariance structure. Classical eigen-decomposition is retained only as an evaluation reference. The framework therefore provides a measurable way to study whether QPCA can represent and distinguish controlled quantum-noise response patterns.
